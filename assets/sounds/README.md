# Sons pour l'application

Placez vos fichiers audio ici. Fichiers nécessaires :

- `click.mp3` - Son pour les clics de boutons normaux
- `pop.mp3` - Son pour les actions rapides (toggle, sélection)
- `success.mp3` - Son pour les actions réussies (partage, favori ajouté)
- `error.mp3` - Son pour les erreurs
- `toggle.mp3` - Son pour les switchs et toggles

## Où trouver des sons gratuits ?

### Sites recommandés :
- **Mixkit** (https://mixkit.co/free-sound-effects/click/) - Sons UI gratuits
- **Freesound** (https://freesound.org/) - Bibliothèque de sons
- **Zapsplat** (https://www.zapsplat.com/) - Effets sonores UI

### Conseils :
- Préférez des fichiers MP3 légers (< 50kb)
- Durée courte (< 0.5 secondes)
- Volume modéré
- Cherchez : "UI click", "button click", "pop sound", "success sound"

## Format
Les fichiers doivent être au format MP3 ou WAV.
